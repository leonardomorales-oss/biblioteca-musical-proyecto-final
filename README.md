# Biblioteca Musical: proyecto final

Aplicación con búsqueda, álbumes destacados, detalle y biblioteca personal.

## Tecnologías

- React
- Vite
- Axios
- Redux Toolkit
- React Router
- Jest

## Instalación y ejecución

```bash
npm install && npm run dev
```

```bash
npm test
```

Comprobaciones disponibles: `npm run lint` y `npm run build`.

## Uso

Prueba búsqueda, detalle, destacados y biblioteca.
